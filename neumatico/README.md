# Partes del neumático: nueva intro

`partes-neumatico-intro-moderna.mp4` reemplaza la introducción visual del video proporcionado por el usuario por una portada con degradado azul, morado y turquesa, título visible desde el primer fotograma e ilustración del neumático original. Un acercamiento suave da paso al montaje original mediante un fundido entre 6,2 y 7 segundos.

La línea de tiempo y el audio original se conservan. Video exportado en 1920 × 1080, H.264; audio AAC copiado sin recodificar. Los fotogramas de la explicación se recodifican para generar un MP4 completo.

## Reproducir

Requiere Python, Pillow, NumPy, FFmpeg y fuentes DejaVu Sans.

```sh
python neumatico/editar_intro.py '/ruta/3. PARTES DEL NEUMATICO.mp4'
```

El archivo original no se incluye en el repositorio. El script genera la portada, una captura de referencia local y el video editado.
